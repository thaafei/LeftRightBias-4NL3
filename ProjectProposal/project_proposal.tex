\section{Task Introduction}

Our project builds a Natural Language Processing model that classifies the main category of a YouTube video. This task is significant because there are more content being uploaded on YouTube everyday,
so classifying videos by category accurately can help filter content. The categories are the following: 
\begin{multicols}{3}
  \begin{enumerate}
    \item Food/Cooking
    \item Video Games
    \item Sports \& Games
    \item Music
    \item Education
    \item Shopping
    \item Vehicles
    \item Lifestyle
    \item News
    \item Health \& Fitness
    \item Business
    \item Digital Media
  \end{enumerate}
\end{multicols}
These categories are determined from YouTube’s category list \href{https://mixedanalytics.com/blog/list-of-youtube-video-category-ids/}{(see here)} 
and our team’s own generalization. Most importantly, it will be interesting 
to analyze the shared commonalities of video titles and descriptions across 
different categories. This task is challenging because most video titles do 
not explicitly state their category and may depend on the channel’s niche 
or current world events. To keep our labels consistent, we’ll write a short
annotation guide with specific cues to look for, then
have everyone in the team label the same starter
set of headlines to line up our interpretations. Our
goal is to reach agreement that’s clearly better than
chance, while recognizing that some headlines will
still be genuinely hard to classify.

\section{Task Definition}
Our dataset consists of YouTube video titles and descriptions, so each input example is a short piece of text. 
The task is a supervised multinomial classification problem: given a title and description, the model predicts the video's primary category. We will use 11 classes, one for each of the categories mentioned above.
We will stick with one label initially, as we are interested in seeing the primary category they are classified in.

\section{Dataset}

\subsection{Plans for Collection}
We will use an existing dataset \textit{youtube-titles.txt} from \url{https://huggingface.co/datasets/AdamLucek/youtube-titles}. 
Each instance contains at minimum the video title \textbf{(video\_title)} and a video description \textbf{(video\_description)}, and also metadata such as the channel\_name, channel\_url, channel\_id and video\_id.

We will use only publicly available data for this course project and follow the dataset's license/usage terms.
We do not plan to perform additional web scraping. Prior to modeling, we will apply basic cleaning
(removing emojis, links, promo codes and text normalization). We will also remove all columns other than the video title and description.

\subsection{Expected Dataset Size}
We expect to use N = 1.5k examples. These are unlabeled, but we can use \href{youtube category checker tools}{https://tubepilot.ai/tools/youtube-category-checker/} to add labels for the remaining samples that our group didn't annotate by hand.
We will create train/dev/test splits with an approximate 80/10/10 ratio (with the exact proportions determined by the outlet-based grouping constraint).
